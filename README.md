# EMLO Telecoms

This repository explores how knowledge graphs can help solve telecom business
problems. It will bring together information about network assets, locations,
capacity, demand, alarms, and maintenance so that relationships between them
can inform operational decisions.

## Problems to explore

- **Demand management:** connect customer and traffic demand to cells, sites,
  and available capacity to identify where growth may create constraints.
- **Predictive maintenance:** connect equipment, alarms, faults, and work
  orders to highlight assets at risk and understand the services or sites they
  could affect.
- **Further telecom use cases:** use the same connected view of network and
  business data to investigate additional operational challenges.

## Knowledge graph approach

The exploration will focus on representing telecom concepts as entities and
their relationships, then using graph queries to answer questions that span
multiple data sources. For example:

- Which sites may be constrained by increasing demand in their cells?
- Which services or sites could be affected by an asset showing repeated
  alarms?
- What other network and maintenance context should inform an intervention?

This repository is an exploratory project; it does not yet provide a deployed
knowledge graph or production decision-support system. Prototypes and
documentation can be added as the use cases and data model are developed.
